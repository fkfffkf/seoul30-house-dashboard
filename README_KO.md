# 서울30평꿀집샀다 — 처음 쓰는 사람용 배포 설명서

이 폴더는 **서울·경기남부 후보 아파트를 최신 실거래 + 과거 거래 + 입지·단지조건으로 비교하는 개인 웹 대시보드**입니다.

## 현재 V1.1에서 되는 것
- 전체 후보군 보기
- 서울/경기남부·우선순위 필터
- 단지 하나를 선택해 최근 24개월 전용 74~84㎡ 실거래 확인
- TARGET 12.42억 / MAX 13.42억 자동 판정
- 최근 거래와 3개월 중앙값·12개월 거래량 비교
- 세대수·준공연도·역거리·초중학교·을지로 통근 등 입지조건 함께 보기
- **네이버부동산 검색 버튼으로 해당 단지의 현재 매물·호가 확인**
- 국토교통부 API를 연결하면 접속 시 최신 데이터를 불러오고 1시간 단위로 갱신

## 경기남부 추가 완료
수지구청·인덕원·철산·평촌을 생활권 이름만 두지 않고 실제 단지로 확장했습니다.
- 수지구청: 현대, 진산마을삼성5차
- 인덕원: 동편마을3단지, 인덕원대우, 인덕원마을삼성
- 철산: 주공12단지, 철산래미안자이 (현재 84㎡ 예산초과권이라 보류)
- 평촌: 초원대림, 한가람삼성, 향촌롯데 (향촌롯데는 현재 예산초과라 보류)

## 1. 공공데이터 API 키 받기
1. data.go.kr 회원가입
2. `국토교통부_아파트 매매 실거래가 자료` 검색
3. 활용신청
4. 발급된 `일반 인증키(Encoding)` 복사

## 2. GitHub에 올리기
이 폴더 안 파일을 하나의 GitHub 저장소(repository)에 올리면 됩니다.
필수 파일: `app.py`, `candidates.csv`, `seed_prices.csv`, `requirements.txt`

## 3. Streamlit에 배포하기
1. streamlit.io 접속 후 Community Cloud 로그인
2. `Create app` → GitHub 저장소 선택
3. Main file path에 `app.py`
4. Advanced settings → Secrets에 아래 입력

```toml
DATA_GO_KR_SERVICE_KEY = "여기에_인증키"
```

5. Deploy

이후 고정 주소(예: `xxxx.streamlit.app`)가 생깁니다. 그 주소만 즐겨찾기하면 됩니다.

## 네이버 매물은 어떻게 보나
단지 상세 화면 오른쪽의 **'네이버부동산에서 이 단지 검색'** 버튼을 누릅니다. 네이버의 현재 매물·호가는 대시보드가 자동 수집하지 않고 네이버 화면에서 직접 확인합니다. 이렇게 분리한 이유는 네이버 매물 데이터에 안정적인 공식 공개 API가 없기 때문입니다.

## 데이터 역할 구분
- **국토부 실거래**: 실제 계약가격의 현재/과거 추적 → 대시보드 자동화
- **네이버부동산**: 지금 시장에 나온 매물과 호가 확인 → 버튼으로 이동
- **후보 단지 조건**: 세대수·연식·역거리·학교·통근 등 장기 비교용

## 현재 버전의 한계
- 네이버 버튼은 네이버 검색을 통해 해당 단지를 찾도록 연결합니다. 네이버의 내부 단지 고유 URL은 변경 가능성이 있어 앱 안에 비공식 크롤링으로 고정하지 않았습니다.
- 실거래 신고는 최근 계약일수록 추가·정정될 수 있습니다.
- 을지로입구 통근시간은 대략적인 비교값이며 실제 출근 시간대 경로와 환승에 따라 달라질 수 있습니다.
